##  Featured Projects

###  [SkySwift AI](https://github.com/shahafsadon/skySwift)

An AI-powered travel planning agent that turns a natural-language conversation into personalized itinerary options with flights, hotels, activities, pricing, and match scores.

- OpenRouter-powered natural language understanding
- Streamed chatbot responses
- Itinerary generation and scoring
- Offline fallback parser
- Optional FastAPI mock server
- Automated tests with Pytest

**Tech:** Python • Streamlit • OpenRouter • Pydantic • FastAPI • HTTPX • Pytest

---

###  [coDrive](https://github.com/shahafsadon/coDrive)

A full-stack cloud-style file management system with web and mobile clients, a RESTful API, and a distributed backend architecture.

- File and folder management, previews, search, sharing, and permissions
- JWT-based authentication and session handling
- React web client and React Native mobile application
- Node.js REST API connected to a C++ TCP server
- Starred, Recent, Shared, and Trash views
- File uploads and downloads across web and mobile
- Dockerized services with a unified Docker Compose setup
- Light and Dark mode support on mobile

**Tech:** React • React Native • Node.js • Express • C++ • JWT • Docker • REST API

---

###  [Schedulix](https://github.com/shahafsadon/Schedulix)

A Python desktop application for generating, ranking, and improving exam schedules under academic constraints.

- Constraint-based schedule generation
- Progressive ranking with a live Top 50 preview
- Manual schedule editing and impact analysis
- Named snapshots and schedule comparison
- Fallback compromise schedules when no fully valid solution exists
- Layered architecture separating GUI, presenters, services, and scheduling logic

**Tech:** Python • Tkinter • Pytest • OOP • Layered Architecture
